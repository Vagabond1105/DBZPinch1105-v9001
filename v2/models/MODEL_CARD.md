# Model card: run classifier (a) and outcome predictor (b), v1.0

Trained 2026-10-20T20:40:44 on `dataset/sweep-2026-10-19`: 2807 finished 32^3 runs (dataset hash `6011a61919e5`), scikit-learn 1.7.2. Generated by `tools/train.py`; see docs/05.2 for the plain-language version.

## What they are

- **(a) Run classifier**: input = the 65 features of a *finished* run (zpinch/analysis/features.py); output = probability of each outcome class.
- **(b) Outcome predictor**: input = only what is known *before* pressing Start (the 8 swept settings and the stability numbers computed from them, e.g. n q: 15 inputs); output = probability of each outcome.
- Both: gradient-boosted trees (`HistGradientBoostingClassifier`), labels = the physics rules (zpinch/analysis/rules.py).

Classes learned: gravity_sag, kink_disruption, quiescent, radiative_collapse, resistive_diffusion, saturated_kink. Left out (fewer than 10 runs): {'kink_growing': 1}.

## Limits

- The labels come from rules, not from experiments. (a) mostly learns the rules back; its use is the probabilities and the disagreements.
- (b) is only meaningful inside the swept box (tools/sweep.py) at 32^3 with the default seed perturbation, pinch radius and background density. The GUI warns outside it.
- Thin classes (radiative collapse, resistive diffusion) have few test runs, so their per-class numbers are uncertain by ±10-20 %.
- The random seed of a run is not an input, so runs with the same settings but different seeds can differ; this caps (b)'s possible accuracy.
