# 05.1 · V3 Phase 1: labelling and explaining runs with physics rules

> [!abstract] One-sentence version
> Every finished run now gets an **outcome class** (for example *kink → disruption*), a **timeline** of what happened when, and an **explanation** built from the run's own energy bookkeeping and from textbook stability criteria. No machine learning is involved yet. On the 1058 overnight runs, the labels reproduce the **Kruskal–Shafranov** kink criterion almost perfectly.

## 1. What Phase 1 is for

The plan ([[05 - V3 Plan]] §8) puts the machine learning in Phase 3. But a model can only learn "this run was a disruption" if someone first tells it which runs were disruptions. Phase 1 is that "someone": a set of **physics rules** that read a run's saved history and decide what happened. These rules:

1. **label the 1109 overnight runs**, which become the training data for Phase 3;
2. **explain** a single run in the program (the *Finish & analyse* button, or `--analyse`);
3. remain the **fallback and the referee** once ML exists. When the ML and the rules disagree, the report says so.

## 2. The pieces

| File | What it does |
|---|---|
| `v2/zpinch/analysis/features.py` | Turns a run's history into **64 named numbers** (features) with units, for example "largest kink amplitude", "fitted growth rate ± error", "energy the magnetic field gave the plasma". |
| `v2/zpinch/analysis/rules.py` | The **labeller**. Each outcome has a detector with commented thresholds. It returns the overall class, any secondary classes, the timeline and a confidence. |

## 3. The outcome classes (and how each is detected)

Amplitudes are in units of the column radius (written *a*). When a run shows several outcomes, the most violent end state names the run and the others are listed as "also". The classes in priority order:

| Class | In words | Rule (threshold → why that value) |
|---|---|---|
| **Radiative collapse** | radiation steals the core's heat; the magnetic field squeezes the cooled core, which then radiates even faster (a runaway) | core temperature ≤ 0.4 **and** core density ≥ 1.5× its start, at the same time. In the sweep the minimum core temperature splits into two groups: below 0.4 (35 runs, most down to 0.05–0.15) and above 0.6. The density condition rules out a column that just cools while it expands. |
| **Kink → disruption** | the corkscrew grows until it tears the column apart | kink ≥ 0.3 *a*, then **within 1 time unit** the column's plasma spreads to 3.5 *a*. Fast break-up starts at a kink of 0.3–0.4 *a*. A column smeared evenly across the whole box would measure 4.8 *a*, so 3.5 *a* means it is mostly gone. |
| **Sausage** | the column necks like a string of sausages | necking ≥ 0.15 *a*, larger than the kink, for ≥ 0.1 time units, **and** the largest distortion of the whole run. |
| **Saturated kink** | the corkscrew grows, then stops; the column survives bent | kink ≥ 0.1 *a* (5× the 0.02 seed) with no disruption. |
| **Gravity sag** | the whole column falls sideways (−y), without bending | gravity on, and the whole column displaced by ≥ 0.5 *a*. If a small kink (< 0.3 *a*) rides on a larger sag, the sag names the run. |
| **Resistive diffusion** | nothing goes unstable; the current slowly leaks outward and heats the plasma (Ohmic heating) | quiet run, core density down to ≤ 0.5×, ≥ 4 % of the energy turned into heat, **and** the resistive time *a*²/η short enough to matter in the run (≤ 2× the run length). |
| **Quiescent** | the column stays close to where it started | none of the above. |
| *Kink still growing* | only when you analyse **early** (GUI, short `--t-end`) | the kink peaks in the last 0.1 time units and still grows at ≥ half its fitted rate. The report says the outcome isn't decided yet, and gives the likely ending from the $nq$ table in §5. No t = 3 sweep run ends this way. |

**Compression is a phase, not a class.** When the circuit drives more than the Bennett current, the magnetic "piston" mostly sweeps the thin background gas into a sheath. The core itself is squeezed only briefly (core density up 30–90 %, then it relaxes). So compression appears in the timeline (64 runs) but never names a run.

**Confidence.** A label is marked *low confidence* when a number it was decided on sits within ±15 % of its threshold, so nudging that threshold would flip the label. The report names the number.

**Analysing early.** If you analyse before t = 1, the report says the label describes the run *so far*. A quiet early run with $nq < 1$ is told roughly when its kink should appear.

**Numerical health.** The report warns when the vacuum floors (the artificial minimum density outside the column) added more than 5 % of the energy, when the energy-budget error passed 0.1 %, or when the run was stopped early.

## 4. What the data changed (the plan's draft vs reality)

Writing the rules *after* the overnight sweep paid off. Five things in the plan's draft taxonomy ([[05 - V3 Plan]] §3) turned out to be wrong or misleading for this solver:

1. **A disruption doesn't look like "kink amplitude above 2.5 *a*".** The kink amplitude is measured *relative to the column radius*. When the column breaks up its radius jumps (1 → 4.7 *a*), so the measured kink *drops*. The real signature is: the kink passes ~0.3 *a*, then the column's plasma spreads toward the wall soon after. That's why the overnight early-stop rule (kink > 2.5 *a*) fired for **no** run.
2. **The "radius" grows during compression.** The radius diagnostic counts everything denser than the background, including swept-up sheath gas. The core density is the honest compression signal.
3. **Sausage-dominated runs don't happen here.** Even the "sausage" stratum (weak B_z, strong fast drive) ended up 104 disruptions, 10 saturated kinks and 0 sausages. In this setup the kink always wins. Necking does appear, but late in radiative collapse, as cold blobs condense along the column. The class stays in the code, and the zero is reported as a result.
4. **Compression doesn't "bounce".** See above: it's a short early phase.
5. **The driven current doesn't set q.** One might expect a stronger current to make the kink worse (q falls as 1/I). But above I ≈ 1.5 the extra current flows mostly in the swept-up sheath, *outside* the column. The **starting** q predicts the outcome much better (q < 0.1: 99 % disrupt, against 91 % using q / I).

## 5. Results on the overnight sweep

1058 runs at 32³ (plus 51 twins at 48³). The full table is in `v2/dataset/sweep-2026-10-19/analysis/summary.txt`.

| Class | All runs | Broad stratum (uniform sample, n = 574) |
|---|---|---|
| Kink → disruption | 435 (41 %) | 45 % |
| Saturated kink | 259 (24 %) | 30 % |
| Gravity sag | 198 (19 %) | 10 % |
| Quiescent | 89 (8 %) | 10 % |
| Resistive diffusion | 47 (4 %) | 3 % |
| Radiative collapse | 30 (3 %) | 2 % |
| Sausage | 0 | 0 |

**Borderline:** 227 of 1058 (21 %) have low confidence. Most are on the saturated-kink ↔ disruption boundary, which is genuinely continuous. These runs are where the Phase 3 classifier can add value.

### The headline: Kruskal–Shafranov falls out of the data

A helix that winds *n* times along the column is kink-unstable when $nq < 1$, where $q = 2\pi a B_z/(L_z B_\theta)$ is the **safety factor** (the field lines' twist compared with the helix's). The seed perturbation excites a helix with $n \approx L_z / 5a$. Grouping the 261 runs without gravity or cooling by $nq$ of that seeded helix:

| $nq$ (seeded helix) | Outcome |
|---|---|
| 0 – 0.25 | **96 of 96 disrupt** |
| 0.25 – 0.5 | 28 disrupt, 7 saturate |
| 0.5 – 1.0 | **43 of 43 saturate** |
| 1.0 – 1.5 | 30 saturate, 16 stay quiet (the transition) |
| above 1.5 | **41 of 41 grow no kink** |

So the rule labels (which never look at q) reproduce the theory's threshold at $nq \approx 1$. They also show that how far below 1 you are decides *how bad* it gets. This is the strongest single result for the demo, and Phase 3's outcome map should reproduce it.

Other numbers:

- **Kink growth rate:** median 0.79 per Alfvén time (10–90 %: 0.59–0.96). That's the expected size for an ideal kink, which grows on the Alfvén time scale.
- **Resolution check:** the label is the same at 32³ and 48³ for **50 of 51** twins. The one change, r00340, is a borderline quiet run that becomes a small saturated kink at 48³.
- **Numerical health:** 182 runs needed vacuum floors worth > 5 % of the energy, and 112 have an energy-budget error above 0.1 % (worst 1.1 %). They are the violent ones: median current 2.2, almost no B_z, near-vacuum heated to ~80 T₀. The numbers are still good enough to label, but the report flags each one.

## 6. How to use it

From `v2/`:

```bash
./run.sh --headless --t-end 3 --preset "Saturated kink (Bz = 0.6)" --analyse
.venv/bin/python tools/analyse.py dataset/sweep-2026-10-19/runs/r00843.npz     # one saved run
.venv/bin/python tools/analyse.py dataset/sweep-2026-10-19                     # the whole sweep
./test.sh                                                                     # 55 tests
```

In the GUI: run for a while, then press **Finish & analyse**.

A report looks like this (default pure Z-pinch, run to t = 1.7):

```
Outcome: Kink -> disruption
Timeline
  t =  0.23 -  0.87  Kink growth              a helical kink grows exponentially
  t =  0.70 -  1.61  Kink -> disruption       the kink tears the column apart ...
What happened and why
  * With no axial field (q = 0) nothing resists bending, so the column is kink-unstable.
    A helical kink grew from t = 0.23 at rate 4.68 +- 0.01 per time unit (0.79 per Alfven time) ...
  * Once the kink passed 0.3 radii (t = 0.70) it kept going ... Paid for by the magnetic
    field (18 % of E0), the drive circuit (10 % of E0); it went into heat (19 %), flow (9 %).
```

## 7. Honest limits

- **The thresholds were tuned on the data they label.** They were chosen from distributions and checked by eye on galleries of ~70 runs across all classes, not tuned to hit a score. But nobody outside has reviewed them yet. The 12 hand-picked test runs guard against silent changes; they don't prove the thresholds are optimal.
- **Thin classes:** only 30 radiative collapses and 47 resistive runs, and no sausages. Phase 3 may need to merge or drop classes, or the sweep can be resumed for another night.
- **Resistive vs numerical diffusion:** an 8-cell-wide column spreads even at the lowest η (core density to ~0.7× by t = 3). The rule requires a short resistive time so that grid diffusion isn't called "resistive", but the two are not fully separable at 32³.
- **The seed picks the helix:** the dominant helix matches the seeded one in 529 of 816 kinked runs. The report says which, so a reader doesn't mistake the seed's choice for the physics' choice.
- **Single label per run:** the timeline shows the sequence, but Phase 3 trains on the overall label.
